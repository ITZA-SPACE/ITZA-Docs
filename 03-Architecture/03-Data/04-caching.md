# Caching

What is cached where, and how stale data is detected.

**Where the code lives**

- `apps/web/src/data`
- `services/science-api/src/itza_science/cache`

---

## Caching

- Key = hash(geometry rounded to 1e-5) + manifest versions + period.
- Browser: IndexedDB (`idb-keyval`); server: content-addressed JSON files in the file cache (`itza_science/cache/files.py`). No index database is used.
- Demo bundles are committed build artifacts (or released assets), regenerated by `pipelines/build_demo.py`.
